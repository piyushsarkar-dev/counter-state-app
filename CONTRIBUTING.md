# Contributing

Thanks for your interest in improving Counter State App.

## Before you open a pull request

- Keep changes focused and easy to review.
- Run `npm run lint` and `npm run build` before submitting.
- Follow the existing Next.js and Tailwind structure already used in the repository.
- Prefer small, targeted updates to the counter flows or shared layout.

## Good contribution ideas

- Improve counter behavior or state handling.
- Add or refine route-level UI in `src/app`.
- Simplify shared components in `src/components`.
- Expand documentation where it helps new contributors.
